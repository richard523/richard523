## Currently building

| Project | What it is |
|---|---|
| [tb-tray](https://github.com/richard523/tb-tray) | System-tray battery indicator for the Turtle Beach Stealth 700 Gen 3 headset on Linux (StatusNotifierItem, GNOME/KDE) |
| [tb-heal](https://github.com/richard523/tb-heal) | One-command healer for the same dongle's audio path — link/battery status, PipeWire suspend wedges, auto-recovery |
| [clearmic](https://github.com/richard523/clearmic) | GNOME/libadwaita app that controls the mic PipeWire DSP chain (rnnoise, de-esser, compressor) from the tray |
| [perfwatch](https://github.com/richard523/perfwatch) | Featherweight GTK4 performance dashboard — PSI, OOM kills, audio xruns, CPU/thermals |
| [system-config-history](https://github.com/richard523/system-config-history) | Dated, reproducible log of every config change and bugfix on my machine since Aug 2026 |

## Gaming & streaming on Linux

Dota 2, Deadlock, TF2, Insurgency: Sandstorm, Bloons TD6 — with the StartupWMClass / gamescope / CEF fixes to make them behave on GNOME Wayland. Streaming and recording run through OBS + PipeWire + xdg portals on a hybrid Intel/NVIDIA rig. Music production in FL Studio (Wine/Bottles) with native PipeWire filter chains instead of EasyEffects.

## Systems & emulation

NES clones in C++ for diagramming and AI tooling, plus assorted C++ exercises. I like emulators, memory layouts, and the parts of gamedev that are really just systems programming.

## Algorithms & LLM experiments

NeetCode grind in Python and TypeScript, and a rotating cast of LLM side projects: Flowise clones, a web LLM chat API, a Discord bot that displays AI-generated art, a Mistral usage tracker.
